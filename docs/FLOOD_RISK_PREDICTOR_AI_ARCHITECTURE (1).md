# Flood Risk Predictor AI Architecture

```text
Simulation Parameters sliders
        ↓
Slider values converted to model feature row
        ↓
Flood risk predictor model
        ↓
Predicted flood_probability
        ↓
Risk label + confidence + predicted peak + emergency actions
        ↓
AI Prediction Result UI
```

Local Weather Forecast is independent and should remain separate from model inference.
